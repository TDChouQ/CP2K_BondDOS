# CP2K BondDOS 方法说明

CP2K 输入里需要加什么见 `docs/CP2K输入设置.md`（软件内“CP2K 输入设置”页）。

本软件分三部分：

1. **态密度 DOS / PDOS**：读取 CP2K `&DFT/&PRINT/&DOS` 输出的 `.dos` / `.pdos`（Γ 点逐轨道文件、展宽 `_curve` 文件、k 点 PDOS 曲线、旧版格式）。
2. **k 点成键 COHP / COOP / COBI**：读取 `&MO_KP`（`.mokp`）与 `&KS_CSR_WRITE`（`*KS_SPIN_s_K_k*.csr`），直接在 CP2K 的 Gaussian 原子轨道（AO）表象中做成键分析。
3. **电荷与原子 PDOS**：用同一份 `.mokp` 做 Mulliken / Löwdin 布居、原子电荷、磁矩、轨道布居，以及**按原子、按轨道分辨的 k 点 PDOS**（不必在 CP2K 中把原子拆成单独 KIND）。

---

## 1. 原生 DOS / PDOS

* CP2K 2026.2 的 k 点计算**只输出展宽后的 PDOS 曲线**（`*-k<n>_curve-1.pdos`，标题 “K-point projected DOS”）；逐轨道的原始 PDOS 只有 Γ 点计算才有。
* `_curve` 文件已按输入的 `WIDTH`（FWHM）展宽，本软件直接使用；“展宽 FWHM” 只作用于逐轨道原始数据（勾选“对已展宽曲线再展宽”可额外卷积）。
* 文件名中的 `k<n>` 是 **KIND 编号**，不是 k 点编号；`ALPHA/BETA` 表示自旋。
* 原始逐轨道数据：每个 MO 计为 1 个态；勾选“按占据数加权”后谱线单位为电子/eV。
* 统计量（窗口 [a, b] 内，能量相对所选零点）：

  * 积分 M₀ = ∫ρ dE；中心 ε = ∫Eρ dE / M₀（如 d 带中心）
  * 宽度 W = √(∫(E−ε)²ρ dE / M₀)；偏度、峰度为三、四阶标准矩
  * 填充率 = 窗口内 E ≤ 0 部分的积分 / M₀；“E≤0 中心”只统计费米能以下
  * 上边缘 ε_u：ρ(E) 的 Hilbert 变换取极大值处（Vojvodic/Xin 等使用的 d 带上边缘描述符）
  * 原始逐轨道数据用离散权重精确求和，**不受显示展宽影响**；曲线数据用梯形积分。

## 2. k 点 COHP / COOP / COBI

### 2.1 数据与约定

* `.mokp`：k 点及权重 wₖ、本征值 εₙₖ（Hartree）、CP2K 实际占据数 fₙₖ、复数 MO 系数 C(k)、原子–AO 对应关系、重叠矩阵 S(k)。
* `.csr`：k 空间 Kohn–Sham 矩阵 H(k)，文本格式 `行 列 实部 虚部`。
* CP2K 约定（`rskp_transform`，已与 v2026.2 源码核对）：H(k) = Σ_R H(R)·exp(+2πi k·R)，R 为邻居原子在 CP2K **回卷坐标**（每个周期方向 s − ANINT(s)）下的晶格平移。
* 用户输入和输出表格中的平移 R 一律以 **`.mokp` 打印的原始坐标** 为准，软件自动换算到 CP2K 内部回卷坐标。

### 2.2 公式（†为共轭转置）

PAIR 模式（A–B 全部周期镜像合计）：

  vₙₖ = 2·Re[ x_A,nk† · M_AB(k) · y_B,nk ]

IMAGE 模式（指定的一根键 A(0)–B(R)）：

  M̃_AB(R) = Σₖ wₖ·exp(−2πi k·R)·M_AB(k)
  vₙₖ = 2·Re[ x_A† · M̃_AB(R)·exp(+2πi k·R) · y_B ]

| 量 | x | y | M | 说明 |
|---|---|---|---|---|
| COHP（AO） | C | C | H − ½(ε_μ+ε_ν)S | 直接 Gaussian AO（默认；矩阵元的规范见 2.6，`RAW` 时为 H 本身） |
| COHP（Löwdin） | Q=S^½C | Q | S^−½ H S^−½ | 正交化表象（MOLOPT 基组下数值偏大，仅定性，见 2.6） |
| COOP | C | C | S | 重叠布居 |
| COBI（Löwdin） | Q | Q | P^σ = Q·diag(f/g)·Q† | Wiberg 型键指数（LOBSTER 的 COBI 定义） |
| COBI（AO） | S·C | C | P^σ·S | Mayer 型键指数 |

能量分辨谱与积分：

  X(E) = Σ g·wₖ·vₙₖ·G(E − εₙₖ)       （g = 2 限制性 / 1 每个 UKS 通道）
  IX = Σ wₖ·fₙₖ·vₙₖ               （fₙₖ 为 CP2K 实际占据数，支持分数占据）

* 报告中的 ICOHP / ICOOP / ICOBI 用实际占据数精确求和，**与展宽、能窗、步长无关**。
* 曲线文件里的积分列（及 LOBSTER 文件中的 ICOHP 列）是谱线的累计积分（满占据容量），对绝缘体在带隙内等于报告值。
* 符号：COHP 负值为成键（图中默认画 −COHP，成键朝正）；COOP、COBI 正值为成键。
* 单位：COHP eV/eV，ICOHP eV；COOP 1/eV，ICOOP 电子；COBI 无量纲。
* 限制性计算的 ICOBI 对 H₂ 类单键约为 1；Löwdin COBI 与 LOBSTER 的定义一致，但 CP2K 的基组不是 LOBSTER 的极小投影基，数值不保证相同。

### 2.3 正确性验证

软件内置一个合成的非正交紧束缚模型（按 CP2K 2026.2 的 `.mokp` / `.csr` 文本格式写出）。对同一模型用 **Γ 点超胞**（3×3×3）独立计算实空间的 ICOHP、ICOOP、Mayer/Wiberg 键指数，k 点 IMAGE 结果与之吻合到 10⁻⁸（AO 与 Löwdin 两种表象）。原始坐标被平移若干晶格矢量时，键长与积分不变。

读取真实数据时会自动检查：

* S(k) 厄米性、正定性与条件数；C†SC = I；HC = SCε（确认 KS 文件与 MO_KP 来自同一电子步）；Tr(PH) = Σwfε；
* 电子数、最高导出轨道是否已空（ADDED_MOS 是否足够）；
* **k 网格混叠指标** max|S̃_μμ(R=0) − 1|：归一化 AO 的对角重叠应为 1，偏离量即有限 k 网格把远处镜像折叠回来的程度；
* **相位约定检查**：重叠 |S̃_AB(R)| 应随 A–B(R) 距离衰减，用 +R / −R 两种解释的加权距离比较；不一致会醒目提示。
* 原子恰好在 ±0.5 分数坐标边界时，用同样的重叠衰减判据确定 CP2K 内部回卷方向。

### 2.4 周期镜像与 k 网格

* IMAGE 模式需要**完整、等权**的 k 网格（`FULL_GRID T`，`SYMMETRY F`）。软件从 k 点列表自动识别网格（含偏移的 Monkhorst–Pack）。
* 有限网格得到的 H̃(R) 是混叠系数：|Rᵢ| > Nᵢ/2 的请求会被拒绝；|Rᵢ| = Nᵢ/2 标记 “Nyquist”；某方向只有 1 个 k 点时标记 “Γ叠加”。正式结果应做 k 网格收敛。
* PAIR 模式不需要区分镜像，单个 Γ 点也可用。

### 2.5 能量零点

自动：无部分占据时取最高占据态（HOCO/VBM），有部分占据时取占据数穿过 1/2 处的能量（费米能估计）。也可选带隙中点或手动输入 CP2K 主输出中的 Fermi energy（绝对值，eV）。零点只影响横轴，不改变占据数与积分。

### 2.6 AO-COHP 的规范（`COHP_GAUGE`，v1.1.0 新增，默认 ECOV）

非正交基下 C†HC 不是平移不变量：周期体系的势能零点是任意的（CP2K 的本征值常为正，E_F 可达 +10 eV），H → H + ΔS 时 ICOHP 改变 Δ·ICOOP。因此**原始 AO-COHP 的大小甚至符号都可能没有化学意义**（实测 FM-MnO 的 Mn–O：原始 ICOHP = +1.02 eV，看起来“反键”）。提供三种规范（只作用于直接 AO 表象，Löwdin 表象本身平移不变）：

| `COHP_GAUGE` | 矩阵元 | 说明 |
|---|---|---|
| `ECOV`（**默认**） | H_μν − ½(ε_μ+ε_ν)·S_μν，ε_μ = H_μμ(R=0) = Σₖwₖ H_μμ(k) | 共价键能 E_cov（Börnsen–Meyer–Grotheer–Fähnle），对 H → H + ΔS 严格不变 |
| `EREF` | H_μν − E_ref·S_μν | 能量从所选能量零点（E_F/HOCO）算起，等于 ICOHP − E_ref·ICOOP |
| `RAW` | H_μν | v1.0.0 的行为；依赖势能零点，只宜在同一计算内比较同类键，使用时程序会提示 |

CP2K 2026.2 实测（PBE/DZVP-MOLOPT-SR-GTH，3×3×3 k 网格）：

| 键（ICOHP，eV） | RAW | ECOV | Löwdin | ICOBI（AO） |
|---|---|---|---|---|
| Si–Si（金刚石） | −1.89 | −4.32 | −29.8 | 0.95 |
| C–C（石墨烯） | −18.46 | −10.92 | −68.8 | 1.25 |
| Mn–O（FM-MnO，UKS，两自旋合计） | +1.02 | −1.34 | −25.3 | 0.30 |

Löwdin 表象的 ICOHP 在含弥散函数的 MOLOPT 基组下数值非常大（正交化后的轨道带长程振荡尾巴），与 LOBSTER（极小基投影）的数值不可比；跨体系比较键强建议优先用 ICOBI / ICOOP，或 ECOV 规范的 ICOHP，并统一基组、赝势。

## 3. 电荷与原子 PDOS

* Mulliken 权重 pμn = Re[C*μn (S C)μn]（单个 AO 可略为负，所有 AO 之和为 1）；Löwdin 权重 |Qμn|²。
* 原子布居 = Σ wₖ fₙₖ pμn（对该原子的 AO 求和）；电荷 = Z_eff − 布居（赝势价电子电荷）。UKS 给出磁矩（up − down）。
* 原子 PDOS = Σ g wₖ pμn G(E − εₙₖ)，可按 s/p/d/f、磁量子数或基组壳层分解；原子组可写元素符号或编号区间（如 `3,5,7-9`）。

## 4. 导出文件

| 文件 | 内容 |
|---|---|
| `*_bonds.csv` | 每根键：原子、元素、平移 R、键长、各自旋 ICOHP/ICOOP/ICOBI、状态 |
| `*_COHP/COOP/COBI_curves.csv` | 展宽谱线与累计积分 |
| `*_orbital_integrals.csv` | 轨道分辨的积分 |
| `*_charges.csv`、`*_grosspop.csv` | 原子电荷、磁矩、轨道布居 |
| `*_atom_pdos.csv` | 每个原子按磁量子数分解的 PDOS |
| `*_report.json` | 输入文件 SHA256、参数、检查结果、所有积分 |
| `COHPCAR / COOPCAR / COBICAR.lobster` | LOBSTER 格式谱线（E−E_F，含 Average 列） |
| `ICOHPLIST / ICOOPLIST / ICOBILIST.lobster` | LOBSTER 4.x 列表格式（含平移） |
| `CHARGE.lobster`、`GROSSPOP.lobster`、`DOSCAR.lobster`、`POSCAR` | 可供 pymatgen / LobsterPy 读取 |

LOBSTER 格式文件首行注明数据来自 CP2K Gaussian AO，**不是 LOBSTER 投影结果**；同一 CP2K 基组下的相对趋势可比，与 VASP+LOBSTER 的绝对数值不宜直接比较。PAIR 模式的键不写入 LOBSTER 文件。

## 5. 未实现 / 边界

* AO_EXPORT_TYPE 为 `GTO_BASIS`（没有 S(k)）时：NMO = NAO 则由 S = (CC†)⁻¹ 重建；否则只能算 RAW 规范的 COHP。

* 非共线、SOC 自旋轨道耦合；多中心 COBI；LOBSTER 的 charge spilling、fatband、Madelung 能、BWDF。
* 点群对称性约化的 k 网格：IMAGE 模式不可用；PAIR 模式和原子布居只对“对称等价的键/原子取平均”后的值有意义（不可约 k 点上的求和不保持单根键的对称性），正式计算请用 `SYMMETRY F`。只做了时间反演约化的网格（CP2K 默认 `FULL_GRID F`、`SYMMETRY F`，k 点数约为一半）会用 H(−k)=H(k)*、S(−k)=S(k)*、C(−k)=C(k)* 自动展开成完整网格（v1.1.0）。
* 偶数 Monkhorst–Pack 网格不含 Γ 点，在 fcc、六方等晶格中会破坏点群对称性（实测 Si 4×4×4：四根等价 Si–Si 键的 ICOHP 相差约 3%）；需要严格等价时用奇数网格。
* 内存约为 nk × NAO × NMO 个复数（MO 系数）；超大体系请减少 k 点或只算 COOP/COBI。
